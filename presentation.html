⚠️ Problem Statement

Context
  • ATS Black Box: Modern recruitment uses Applicant Tracking Systems (ATS) that auto-reject 75% of resumes based on algorithms. Candidates don't know why.
  • Lack of Real-time Review: Hiring consultancy fees are high, and static online builders provide no keyword density feedback.
  • Interview Anxiety: Candidates struggle with tech-round interviews due to lack of customized behavioral/technical mock practice.
  • Inefficient Roadmaps: Generic roadmaps are available, but none evaluate the candidate's existing skill gap.

🚨 Key Statistics

75%+ of resumes are screened out before a human recruiter sees them.

80%+ candidates struggle to verbalize their experience in technical interviews.

🏗️ System Architecture

Tech Stack
  • Frontend: Angular 19 (Standalone Architecture) + Tailwind CSS (v4) + Angular Material. State management relies on Angular Signals.
  • Backend: Node.js with Express framework, secured with Helmet, Rate-Limit, and CORS.
  • Databases: Unified database layer supporting **SQLite** (local `.db` file) and **MySQL** seamlessly.
  • AI Integration: Google Generative AI SDK using the **Gemini 1.5 Flash** model.

🔥 Modern Frontend

Uses reactive signals (`signal`, `computed`) for smooth view rendering and robust state handling.

💾 Offline Capability

Includes complete Mock Fallback Engines if Gemini API keys are not configured, ensuring 100% test reliability.

🗄️ Database Schema

Data Layer
  • Users Table: Stores registration detail, role flags (user, recruiter, admin) and password hashes.
  • Resumes & Versions: Holds the parsed text, PDF uploads, and historical versions of edits.
  • ATS Reports Table: Links to resumes and stores score arrays, formatting evaluations, and missing keywords in JSON.
  • Interview Tables: Track session stats, scores, question texts, and transcripted answers with voice metrics feedback.

CREATE TABLE resumes (id INTEGER PRIMARY KEY, user_id, extracted_text);
CREATE TABLE ats_reports (id INTEGER PRIMARY KEY, resume_id, overall_score);
CREATE TABLE interview_sessions (id INTEGER, user_id, overall_score, feedback_json);

🧠 Google Gemini AI Integration

AI Layer
  • Model Used: `gemini-1.5-flash` for high-speed, cost-efficient, and accurate text processing.
  • Structured Output: Prompts are engineered to return strict JSON syntax, which is safely parsed by the backend: { "overallScore": 85, "weaknesses": [...] }
  • Context Management: For the Mentor Chatbot, complete conversation history + user resume JSON is fed to Gemini to generate custom advice.

🎭 Robust Error Handling

The code uses safe JSON cleaning regex methods (`.replace(/^```json/i, '')`) to extract data from raw markdown envelopes returned by the AI model. Includes structured try/catch modules with safe static mock backups.
